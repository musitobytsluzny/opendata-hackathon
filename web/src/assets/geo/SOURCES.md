# Map boundaries

`cesko.json` is the Czechia feature (`ADM0_A3=CZE`) extracted from Natural Earth's
1:10m Admin 0 countries dataset. Only the properties were reduced; the geometry
is unchanged. Natural Earth data is public domain.

Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_10m_admin_0_countries.geojson
License: https://www.naturalearthdata.com/about/terms-of-use/

The pre-existing Plzeň region and district boundaries remain unchanged.
